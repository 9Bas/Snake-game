# Snake-game
เกมงูเขียนด้วย HTML + JavaScript เปิดเล่นในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่มบังคับงูให้กินแอปเปิ้ล ยิ่งกินเยอะ งูยิ่งยาว และยิ่งเร็วขึ้น แต่ห้ามชนขอบจอหรือชนตัวเอง
---
## จุดเด่นของเกม
- มีแอปเปิ้ลบนหน้าจอพร้อมกัน 5 ลูก
- ลำตัวงูเปลี่ยนสีเป็นลายสีรุ้งไปเรื่อย ๆ
- มีเสียงทุกครั้งที่กินแอปเปิ้ล
- ยิ่งคะแนนสูง งูยิ่งวิ่งเร็วขึ้น
---
##ปุ่มควบคุม
| การกระทำ | ปุ่ม |
|---|---|
| เลี้ยวขึ้น | ↑ หรือ `W` |
| เลี้ยวลง | ↓ หรือ `S` |
| เลี้ยวซ้าย | ← หรือ `A` |
| เลี้ยวขวา | → หรือ `D` |
| เริ่มเกมใหม่ (หลังแพ้) | `Space` (spacebar) |
---
##กติกา
- กินแอปเปิ้ล 1 ลูก = **+1 คะแนน** และงูยาวขึ้น 1 ช่อง
- ชนขอบจอ = แพ้
- ชนตัวเอง = แพ้
- เมื่อแพ้ จะขึ้นข้อความ Game Over พร้อมคะแนน กด `Space` เพื่อเล่นใหม่
### ความเร็วของงู
| คะแนน | ความเร็ว |
|---|---|
| 0 – 10 | ปกติ (7) |
| มากกว่า 10 | เร็วขึ้น (9) |
| มากกว่า 20 | เร็วสุด (11) |
##โครงสร้างไฟล์
```
📦 snake-game
 ┣ 📄 index.html   → หน้าเว็บหลัก (เปิดไฟล์นี้เพื่อเล่น)
 ┣ 📄 mainG.js     → ตัวเกมหลัก: วาดงู วาดแอปเปิ้ล นับคะแนน เช็คชน
 ┣ 📄 inputG.js    → รับค่าปุ่มที่กดจากคีย์บอร์ด
 ┗ 🔊 gulp.mp3     → เสียงตอนกินแอปเปิ้ล
```
